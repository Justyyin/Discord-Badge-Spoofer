# Sicherheit / Security

## 🇩🇪 Deutsch

**Poste niemals** Discord-Tokens, Passwörter, Analytics-Tokens, Cookies oder ungekürzte Konsolen-Logs in Issues, Pull Requests oder Diskussionen. Wer dein Token hat, hat Zugriff auf dein Konto.

- Hast du versehentlich ein Token veröffentlicht? **Ändere sofort dein Discord-Passwort** – dadurch wird das Token ungültig. Lösche danach den Beitrag.
- Konsolenausgaben vor dem Teilen kürzen: Benutzernamen, IDs und alles, was wie ein langer zufälliger String aussieht, entfernen.
- Wenn dich jemand auffordert, Code in die Discord-Konsole einzufügen, den du nicht verstehst, ist das sehr wahrscheinlich ein Betrugsversuch („Self-XSS“).

### Sicherheitsprobleme melden

Dieses Repository enthält keinen ausführbaren Code. Findest du in der **Dokumentation** einen Schritt, der Nutzer gefährden könnte (z. B. einen Link zu Schadsoftware oder eine irreführende Anweisung), melde ihn bitte **vertraulich** über **Security → Report a vulnerability** in diesem Repository statt über ein öffentliches Issue.

Sicherheitsprobleme im **Originalskript** betreffen den [Gist von nvckai](https://gist.github.com/nvckai/b258c253fa00e4300888f5cb13a905b5), Probleme in **Discord** selbst bitte an das [Discord-Bug-Bounty-Programm](https://discord.com/security).

## 🇬🇧 English

**Never post** Discord tokens, passwords, analytics tokens, cookies or unredacted console logs in issues, pull requests or discussions. Anyone with your token has access to your account.

- Accidentally published a token? **Change your Discord password immediately** – this invalidates the token. Then delete the post.
- Redact console output before sharing: remove usernames, IDs and anything that looks like a long random string.
- If someone asks you to paste code you don't understand into the Discord console, it is very likely a scam ("self-XSS").

### Reporting security issues

This repository contains no executable code. If a step in the **documentation** could put users at risk (e.g. a link to malware or misleading instructions), please report it **privately** via **Security → Report a vulnerability** in this repository instead of opening a public issue.

Security issues in the **original script** belong to [nvckai's Gist](https://gist.github.com/nvckai/b258c253fa00e4300888f5cb13a905b5); issues in **Discord** itself go to [Discord's bug bounty program](https://discord.com/security).
