# Mitwirken / Contributing

🇩🇪 [Deutsch](#deutsch) · 🇬🇧 [English](#english)

## Deutsch

Danke, dass du helfen möchtest! Dieses Repository enthält **nur Dokumentation** – keinen ausführbaren Code.

### Willkommen

- Korrekturen von Tippfehlern, Grammatik und Übersetzungen
- Hinweise, dass ein Schritt nicht mehr zum aktuellen Gist oder Discord-Client passt
- Bessere Erklärungen, neue FAQ-Einträge, defekte Links
- Verbesserte schematische Abbildungen (bitte als eigene Werke, keine echten Discord-Screenshots mit persönlichen Daten)

### Nicht angenommen

- Kopien oder Abwandlungen des Originalskripts von nvckai (keine Weiterverbreitungslizenz erkennbar – siehe [`LICENSE-NOTICE.md`](LICENSE-NOTICE.md))
- Anleitungen zum Umgehen von Discord-Schutzmechanismen, Token-Extraktion oder Ähnliches
- Links zu inoffiziellen „Fixes“, Mods oder Drittanbieter-Clients

### Regeln für Änderungen

1. **Beide Sprachen synchron halten.** Eine Änderung in `README_DE.md` braucht eine entsprechende Änderung in `README_EN.md` (und umgekehrt). Wenn du nur eine Sprache kannst, schreib das in den Pull Request – jemand anderes ergänzt die Übersetzung.
2. **Überschriften nur mit Bedacht ändern.** Die Startseite `README.md` verlinkt auf Abschnitts-Anker; geänderte Überschriften müssen dort mit angepasst werden.
3. **Bilder** als PNG (Diagramme) oder JPG (Fotos), Breite höchstens ca. 1600 px, möglichst unter 300 KB. Ablage in `assets/images/`.
4. **Datum aktualisieren.** Wenn du den Inhalt gegen eine neue Gist-Version prüfst, aktualisiere das Prüfdatum in [`SOURCE.md`](SOURCE.md).
5. Die GitHub-Action **Docs CI** prüft Markdown-Stil und Links automatisch.

## English

Thanks for helping! This repository contains **documentation only** – no executable code.

### Welcome

- Fixes for typos, grammar and translations
- Reports that a step no longer matches the current Gist or Discord client
- Clearer explanations, new FAQ entries, broken links
- Improved schematic illustrations (your own work please – no real Discord screenshots containing personal data)

### Not accepted

- Copies or modified versions of nvckai's original script (no redistribution license visible – see [`LICENSE-NOTICE.md`](LICENSE-NOTICE.md))
- Instructions for bypassing Discord safeguards, extracting tokens or similar
- Links to unofficial "fixes", mods or third-party clients

### Rules for changes

1. **Keep both languages in sync.** A change to `README_EN.md` needs a matching change to `README_DE.md` (and vice versa). If you only speak one language, say so in the pull request and someone else will add the translation.
2. **Change headings carefully.** The landing page `README.md` links to section anchors; renamed headings must be updated there too.
3. **Images:** PNG for diagrams, JPG for photos, max. ~1600 px wide, ideally under 300 KB. Store them in `assets/images/`.
4. **Update the date.** If you re-check the content against a new Gist version, update the review date in [`SOURCE.md`](SOURCE.md).
5. The **Docs CI** GitHub Action checks Markdown style and links automatically.
